주요 구성 요소는 다음과 같습니다.

  • 웹 서버: EC2 + Apache (정적 자원 핸들링 및 리버스 프록시 구성)
  • 애플리케이션 서버: EC2 + PHP (RESTful 비즈니스 로직 처리 계층)
  • 데이터베이스: Amazon RDS + MySQL (Multi-AZ 이중화 및 자동 백업 적용)
  • 보안 설정: Security Group 최소 권한 원칙 및 안전한 IAM 역할 바인딩
SecurityGroup-Inbound-Rules.sh Bash 
# Web Tier -> App Tier 포트 오픈 (내부 통신)
aws ec2 authorize-security-group-ingress \
  --group-id sg-01234apptier \
  --protocol tcp --port 8080 \
  --source-group sg-01234webtier
