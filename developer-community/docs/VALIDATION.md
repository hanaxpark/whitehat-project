# 원본 UI 적용판 검증 기록

2026-10-01 (Asia/Seoul), Node.js 24.14.0, Vite 7.3.6.

## 자동 검증

테스트 8개 통과: JWT 저장/Authorization/raw JSON/204/오류; 일반 사용자 글/댓글/좋아요/프로필; 관리자 미로그인 401 및 일반 계정 403; 타인 글/댓글 관리자 삭제; 삭제 사유 검증; 게시글 삭제 시 연결 댓글 정리; mock 감사 기록/영속성; 가입/프로필 요청이나 이메일로 관리자 승격 불가; 팀원 username/필드명/댓글/좋아요 계약 유지; 관리자 목록 서버 페이징 및 snake_case 매핑; 신규 API 미구현/잘못된 응답 오류.

실제 API 모드와 mock 모드 모두 빌드 확인. API 빌드에서 mock 데모 계정/비밀번호가 포함되지 않는 것 확인.

## 브라우저 검증

- `/admin` 비로그인 접근 시 로그인 안내, 로그인 후 원래 경로 복귀.
- demo 일반 계정의 관리자 접근 차단, 관리자 헤더 링크 숨김.
- admin mock 계정 로그인 후 관리자 링크/운영 현황/목록 정상 표시.
- 댓글 삭제창: 비어 있는 사유는 확인 버튼 비활성, 사유 입력 후 삭제 완료/개수 감소.
- 관리자 타인 게시글 삭제 및 연결 댓글 제거.
- 사용자 목록의 ID/이메일/닉네임/가입일/권한 확인, 닉네임 검색 필터 반영.
- 390px 모바일 관리자 목록에서 문서 가로 넘침 없음. 메뉴/표는 각 영역 내부 가로 스크롤.
- 새 Stitch HTML/CSS를 기준으로 메인, 목록, 상세, 작성, 로그인, 프로필, 관리자 현황과 관리 목록을 실제 브라우저에서 확인했습니다.
- 최종 `npm test` 8개 통과, `npm run build` 성공. 브라우저의 검증용 데이터는 ZIP에 포함되지 않습니다.

## 미검증 범위

실제 Users/Contents 백엔드 연결, 운영 role migration/권한 미들웨어/삭제/감사 저장, AWS/ALB/EC2 배포, Nginx 런타임은 확인하지 않았습니다. 관리자 서버 계약은 신규 제안이며 ADMIN_API.md의 구현 및 통합 검증이 필요합니다. 관리자 현황은 새로 첨부한 `7._admin_center/code.html`의 서식을 적용했습니다.
